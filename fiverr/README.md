## Rules to stay safe on Fiverr
- Demos are labeled "concept" — never claim they were paid client work.
- Never ask for payment or contact outside Fiverr (instant ban risk).
- You can use AI tools (including Claude) to build, but you are responsible for the quality; always test before delivering.
- Gig 4 needs an API key per client: the client pays their own Claude/OpenAI usage. Say this in the gig.
